# Stratim
### Описание
Репозиторий для анализа, предразметки и детекции техники по проекту стратима
### Работа с предразметкой
#### Описание директорий

- **assets/**: содержит модели, изображения и видео для инференса.
  - **model/**: директория с моделью YOLOv8.
  - **images/**: директория с изображениями для обработки.
  - **video/**: директория с видеофайлами для обработки.

- **predrazmetka/**: основная рабочая директория.
  - **inference.py**: основной скрипт для выполнения инференса.
  - **configs/config_classes.py**: классы конфигурации для модели и данных.
  - **tests/**: папка с тестовыми конфигурациями и скриптами.
    - **test_config.yaml**: пример конфигурационного файла для тестирования.
    - **run_test.sh**: bash-скрипт для запуска теста инференса.
  - **nn/**: папка с классом модели и пре-/пост- обработкой.
  - **tools/**: папка с основными скриптами для работы с данными.
  - **configs/**: скрипт с реализацией конфига.

#### Установка

   ```bash
    git clone https://gitflic.ru/project/adulebo/stratim.git
    cd stratim/predrazmetka
    python3 -m venv env
    source env/bin/activate
    python3 -m pip install -e .
   ```
#### Конфигурация
Конфигурация инференса осуществляется через YAML-файл. Пример конфигурации находится в `predrazmetka/tests/test_config.yaml`.

- **model**:
  - `path`: путь к файлу модели YOLOv8.
  - `device`: устройство для инференса (`cpu` или `cuda:0`).
  - `conf`: порог уверенности для предсказаний.
  - `iou`: порог IoU для NMS.
  - `imgsz`: размер изображения для обработки.
  - `names`: список классов.

- **data**:
  - `paths`: список путей к директориям с изображениями и/или видео.
  - `skip_frames`: количество кадров для пропуска при обработке видео.
  - `intervals`: список интервалов времени (в секундах) для обработки видео.
  - `save_result_dir`: директория для сохранения результатов инференса.
  - `save_imgs_with_prediction_bbox`: флаг для сохранения изображений с предсказанными боксами.
  - `save_coco_annotations`: флаг для сохранения аннотаций в формате COCO.
  - `save_zip`: флаг для сохранения zip-архива с аннотациями и изображениями/кадрами из видео.
  - `check_duplicates`: флаг для проверки дубликатов по хешу.

#### Запуск теста
``` bash
cd predrazmetka
chmod +x tests/pytest.sh
./tests/pytest.sh
```
Результаты теста будут сохранены в директорию, указанную в параметре `save_result_dir` конфигурационного файла (по умолчанию `./results`). Если включены соответствующие опции, вы получите:

- Изображения с предсказанными боксами.
- Аннотации в формате COCO (`annotations_coco.json`).
- Zip-архив с аннотациями и сырыми изображениями/кадрами из видео.

#### Запуск инференса
За основу конфигурационного файла можно использовать тестовый конфиг. Для запуска инференса достаточно запустить inference.py с указанием конфига

 ```bash
   python inference.py --config path/to/custom/config.yaml
```
#### Доп. информация
- **Логирование**: Скрипт `inference.py` настроен на вывод логов уровня INFO.
- **Очистка временных файлов**: После завершения инференса временные файлы очищаются автоматически.
- **Проверка дубликатов**: Если включена проверка дубликатов, изображения с одинаковыми хешами будут пропущены.

### Работа с репозиторием
Для сохранения единой стилистики используется pre-commit - инструмент для автоматической проверки кода перед отправкой в репозиторий. Перед началом работы требуется выполнить следущее в рабочей папке:
``` python
python3 -m pip install pre-commit
pre-commit install

# можно пользоваться проверкой кода перед коммитом самостоятельно
pre-commit run --all-files
```
Например, после правки кода, хочется сделать коммит. В консоли после коммита произойдет проверка кода с частичными исправлениями. Часть хуков придется поправить самому - будет показано, в каком файле и в какой строчке. Если хочется отключить, в коммит нужно добавить:
``` python
git commit -m "Some comments" --no-verify
```
